How this list works · ranking & status definitions

Ideas are ranked by career signal value — visibility to hiring managers, technical depth, and open-source appeal. Rankings favor Rust/systems work, data engineering angles (Databricks/GCP), and projects that extend the existing wsr / codetwin ecosystem. To propose an idea, open an issue.

Last audited on 2026-11-06: all 27 ranked ideas, five graveyard entries, and eight additional related repositories; GitHub evidence and relevant local checkouts were inspected. Rankings are preserved. idea means proposed or no implementation/scaffold evidence, including README-only repository setup; in-progress includes implementation/scaffolds and maintained projects with remaining work; done means the core deliverable is shipped, not that maintenance has ended. Unavailable repositories remain unresolved rather than assumed absent. See review evidence for per-idea findings, access limits, and validation scope.

#03in-progressEffort L

Rust, proc-macros, pyo3, napi-rs, WASI / WIT

An annotated-Rust binding SDK scaffold organized into SDK, CLI, adapter, core, macro, shared-type, and Python/Node/WASI crates, plus xtask. Career signal & build details

Key features to build:

  • CLI for inspection, validation, and code generation; extensible via custom BindingAdapter trait
